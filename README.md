# InstaTube 3.0

**InstaTube** (`v3.0.0`, package `dev.xboyrex.instatube`) is a native Android media extraction studio and floating overlay assistant for **Instagram** and **YouTube**, architected by **ㅤᏞᴀᴢʏㅤᎷꫝʏᴀɴк まやんく (`Mayank · @xboyrex`)**.

## Core Capabilities
- **Floating Overlay Assistant (`SYSTEM_ALERT_WINDOW`)**:
  - Draggable edge bubble & instant floating action card over Instagram and YouTube.
  - Copy or share any Reel, Post, Short, or Video link while inside Instagram/YouTube to trigger the floating download card (**Save Video**, **Audio M4A**, **Save Cover**, **Copy Caption**) without leaving the app.
- **Live Status Bar Notification Engine**:
  - Real-time progress bar notifications (`%`, `MB / Total MB`, platform tag) and heads-up completion alerts with quick **Open Vault** actions.
- **Instagram & YouTube Extraction Studio**:
  - **Instagram**: Full HD Reels, Videos, Carousels, Profile Browser (`@username`), demuxed `.m4a` audio tracks, `.jpg` covers, and 1-tap caption copy.
  - **YouTube**: Multi-threaded `144p` to `4K` MP4 video+audio muxing, `.m4a` audio streams, `maxresdefault` HD covers, and full description copy.
- **Android 7.0 – 17 Support**: `minSdk = 24`, `targetSdk = 36`, `compileSdk = 37`.
